# Security

If you find a security problem in MO2 Revamped (for example in the installer,
the nxm link handler or the native DLL loader), please don't open a public
issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ArialSenki/MO2-Revamped/security/advisories/new)
instead.

Include the version, what an attacker could do and how to reproduce it. I'll
reply as soon as I can and credit you in the changelog unless you'd rather not
be named.

Only the latest release gets security fixes.
