MO2 Revamped 1.0.2 adds **Elden Ring Nightreign**, makes saves safer for
Elden Ring and Nightreign, and brings back the complete installation: one
MO2 Revamped for every game MO2 supports. Isolated copies for one game are now
made inside MO2 from the New instance wizard.

## Download

- `MO2-Revamped-Setup-1.0.2.exe`: run it and choose **Install MO2 Revamped**,
  or **Update MO2 Revamped** to keep an existing installation and its data.
- `SHA256SUMS.txt`: `4F5E1F599095117A81871F391CEC2E7E7680DB8F18FBA6398A408ACBAFA30B25`

The installer is not digitally signed, so Windows SmartScreen may warn about it.

## Highlights

- **Elden Ring Nightreign**: save isolation, named save profiles, automatic
  save backups, the launch save guard, native DLL loading, the Native DLL
  Profile, startup options and the archive installer. Works with Seamless
  Co-op and me3.
- **Safer saves**: while the game runs from an isolated profile, the Steam
  save folders are set aside and come back unchanged when it closes, with every
  launcher. Saves are backed up before each launch and can be restored from
  Save Isolation; a save left by a game started from Steam is kept and named.
- **Fluent dialogs**: Profiles, Executables, Notifications and Manage
  Overwrite use the instance manager's card layout; context menus follow
  Windows 11.
- **Installer**: names programs still using the files before an update or
  uninstall, reinstalls next to data an uninstall kept, follows the Windows
  accent colour and light or dark mode, and shows progress on the taskbar.
- **Fixes** for Bethesda games (plugin names, edition selection), instances,
  crash dumps, Help menu entries and translations.
