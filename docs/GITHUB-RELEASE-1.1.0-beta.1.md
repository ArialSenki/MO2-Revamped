MO2 Revamped 1.1.0 beta 1 is a **pre-release**: Seamless Co-op runs from its
MO2 mod with every other mod, the remaining dialogs get the Fluent design, and
every window was reviewed in Light and Dark. A few details are still under
review; 1.0.2 stays the stable release.

## Download

- `MO2-Revamped-Setup-1.1.0-beta.1.exe`: run it and choose **Install MO2
  Revamped**, or **Update MO2 Revamped** to keep an existing installation and
  its data.
- `SHA256SUMS.txt`: checksum of the installer.

The installer is not digitally signed, so Windows SmartScreen may warn about it.

## Highlights

- **Seamless Co-op from MO2**: its mod runs inside the VFS with every other
  mod and native DLL, its launcher hands over to the game started from MO2,
  and a missing session password stops with a prompt instead of a crash.
- **Native DLL profile**: one list of every native DLL of the active mods,
  Seamless Co-op included, switched on by default.
- **Fluent design**: Categories, Forced load, Mod information, Overwrite,
  Already installed, New profile, About, Startup options, the archive
  installer and more use the card layout; Windows 11 scroll bars.
- **Themes**: Light and Dark (blue); Dark Black is retired.
- **Design review**: glyph buttons that vanished on Dark, aligned fields and
  lists, page titles that match the menus, and Spanish texts revised
  throughout.
- **Developer mode (hidden)**: beta integrations for me3 and Mod Engine 2,
  off by default and not needed to play.

The full list is in the [changelog](https://github.com/ArialSenki/MO2-Revamped/blob/v1.1.0-beta.1/CHANGELOG.md).
