# Nexus publication copy — MO2 Revamped 1.0.1

## File title

MO2 Revamped 1.0.1 — Main Setup

## Upload file

`MO2-Revamped-Setup-1.0.1.exe`

## English description

MO2 Revamped is a community edition of Mod Organizer 2, maintained by
ArialSenki and focused on Elden Ring modding. It keeps MO2's familiar workflow
while adding Elden Ring tools and a coordinated interface refresh.

### Highlights

- Choose between Light, Dark Blue, and Dark Black themes.
- Refined the main window, menus, file panes, filters, category manager,
  Overwrite view, and log area.
- Data, Saves, and Downloads columns adapt to the window and can still be
  resized manually.
- Elden Ring archive installation offers a clear choice between preserving
  the archive structure and using standard MO2 layout.
- The redesigned installer installs the isolated Elden Ring edition and
  updates, restores, and uninstalls it from one setup file. The Standard
  multi-instance installation and "Copy data" are coming soon.
- Interface and plugins in English, Spanish, German, French, Italian, and
  Brazilian Portuguese; MO2 starts in the language chosen in setup.
- New Startup option to skip the intro logo screens.

### Installation

Run `MO2-Revamped-Setup-1.0.1.exe` and choose **Install isolated Elden Ring**.
It creates one portable MO2 for Elden Ring that keeps its data beside the
installation. Use the other installer actions to update, restore, or uninstall
an existing Revamped installation.

To avoid the online connection notices when the logos are skipped, set
**System > Network > Launch Setting** to **Play Offline** in the game.

### Support

Install, update and uninstall were tested end to end. Back up your MO2 data
before using maintenance actions, and report problems with the steps to
reproduce them and the relevant MO2 or installer log.

MO2 Revamped is a community project, not an official Mod Organizer 2 release.

## Descripción en español

MO2 Revamped es una edición comunitaria de Mod Organizer 2, mantenida por
ArialSenki y centrada en la gestión de mods de Elden Ring. Conserva el flujo
habitual de MO2 e incorpora herramientas para Elden Ring y una interfaz
rediseñada.

- Temas Light, Dark Blue y Dark Black.
- Menús, paneles de archivos, filtros, categorías, Overwrite y registro con un
  diseño más coherente.
- Las columnas de Data, Saves y Downloads se ajustan al tamaño de la ventana y
  permiten redimensionamiento manual.
- El instalador de archivos de Elden Ring permite conservar la estructura del
  archivo o usar la organización estándar de MO2.
- Un único instalador instala la edición aislada de Elden Ring y permite
  actualizarla, restaurarla y desinstalarla. La instalación estándar con
  varias instancias y "Copiar datos" llegarán más adelante.
- Interfaz y plugins en inglés, español, alemán, francés, italiano y
  portugués de Brasil; MO2 arranca en el idioma elegido en el instalador.
- Nueva opción de inicio para omitir las pantallas de logos iniciales.

Ejecuta el archivo y selecciona **Instalar Elden Ring aislado**. Se crea un
MO2 portable para Elden Ring que guarda sus datos junto a la instalación.

Para evitar los avisos de conexión al omitir los logos, en el juego ve a
**Sistema > Red > Ajuste de inicio** y elige **Jugar sin conexión**.

La instalación, la actualización y la desinstalación se probaron de principio
a fin. Haz una copia de seguridad de los datos de MO2 antes de usar las acciones de
mantenimiento y comparte los pasos para reproducir cualquier problema junto
con el registro correspondiente.
