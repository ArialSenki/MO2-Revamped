# Contributing

Use GitHub Issues to discuss a defect or proposed change before opening a pull
request. Keep changes focused on one behavior and describe how it was checked.

For a bug report, include the MO2 Revamped revision, relevant component, game
version when applicable, and concise reproduction steps. Remove personal paths,
usernames, credentials, save files, and unrelated log data before attaching
diagnostics.

When modifying upstream-derived code, preserve its copyright notices and
license terms. Add or update third-party notices whenever a dependency or
licensed asset changes.
